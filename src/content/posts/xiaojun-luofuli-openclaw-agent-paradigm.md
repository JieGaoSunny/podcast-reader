## 编者按

这是一期信息密度极高的对话。张小俊与罗福莉——媒体口中的"AI 天才少女"、小米大模型团队负责人——进行了近三个小时的深度访谈。话题从她春节期间使用 OpenClaw 的顿悟体验出发，延伸至 Agent 框架的本质、MiMo V2 系列模型的技术决策、多模态统一架构的探索，最终触及 AGI 的时间线判断。

罗福莉的叙述有一个鲜明特点：她不回避自己认知转变的过程。从最初排斥 OpenClaw，到凌晨两点装上后一直用到天亮；从认为"这只是交互创新"，到将其定义为"划时代的 Agent 框架"——这种坦诚让整期访谈充满了真实的思考张力。

## 一、从排斥到顿悟：OpenClaw 的三天冲击

罗福莉坦言，她一开始对 OpenClaw 是排斥的。

> 我1月份第一次看到这个东西的时候，大概也是这样的认知——就是 Cursor 加一个 Agent 的、更有利于交互的 UI 设计。再加上它的创始人非常擅长贴着 Agent 的概念做一些很玄幻的运营动作，包括"Skill"、"Hype"这些，就让你更排斥。

转变发生在春节。一个深夜她花两小时装上 OpenClaw，从凌晨两点用到早上六点。

> 那一晚上我觉得我脑内的不知道是多巴胺还是内啡肽，就持续在分泌，让我兴奋到完全睡不着觉。

**第一天**的感受是产品设计的极致——时间感知、温度关怀、精细编排的 Context。**第二天**，她开始把工作中的事情交给它——团队管理、人员筛选、组织架构设计，发现它全部做出来了。**第三天**，她尝试把研究任务交给它——构建 User Simulator，一两个小时就有了一个可用的成果。

> 从一个我最开始对它认知只是"一个有灵魂有温度的产品设计"，到它可以帮我替代我生活或工作当中的一部分，到最后它能促进我的研究。这也就是三天发生的事情。

## 二、OpenClaw 为什么比 Cursor 好

罗福莉深入分析了框架差异：

**持久化记忆体系**——OpenClaw 对 Memory 有分层和分级，这在 Cursor 中完全没有。

**多模型联合利用**——在 Cursor 中，如果模型视频理解不行，你得自己配更好的模型。但在 OpenClaw 中直接发视频给它，它会自己找合适的模型。

> 这种自主去面对当代模型的缺点，然后在框架上去补齐这个缺点的能力，是有点超乎我意料的。

她提出了一个关键洞察：**OpenClaw 的产品逻辑是通过 Agent 编排来弥补模型短板**。这与 Claude 的逻辑不同——你用 Claude 是因为模型本身强大；你用 OpenClaw 是因为框架能让中等模型发挥超预期的水平。

实验验证了这一点：她把 MiMo V2 Flash（当时没有做针对性训练）甚至 3B 的端侧模型接上 OpenClaw，发现在复杂 Agent 框架下，小模型也能完成她认为不可能的任务。

> 这是我第一次感受到，原来一套非常复杂的框架设计，它是能够弥补非常多模型能力短板的。

---

## 三、自学习：顶级模型与顶级框架的共进化

罗福莉描述了她对"自学习"的独特理解。

她用 Claude 4.6 Opus 高强度使用一周（第一天就快1000美元），沉淀了大量 Skills 和 System Prompt，甚至改了 OpenClaw 的源码——Memory 系统、Agent Workflow。然后切换到 Sonnet、国内模型，发现整套框架依然非常强大。

> 这也是我为什么觉得顶尖的模型应该跟顶尖的 Agent 框架共同往前去进步。我在这个事情上是第一次感受到了一个 Agent 的自学习到底是怎么发生的。

她总结的路径：模型在进步时，也在改变 Agent 框架——包括静态信息（Memory）和动态信息（架构设计）。如何在提升模型能力的同时提升框架与模型的适配程度，就是她思考的"自学习"。

## 四、群体智能的爆发

春节回来后，罗福莉下了一个"指令"：第二天 OpenClaw 对话次数不超过100的人可以直接淘汰。

> 我没有想过说第二天有人对话次数没超过100，我真的会把他淘汰。我只是想给大家表达一种态度：你不用，你可能真的要落后了。

结果出乎意料。近百人的群里，所有人疯狂互相激发想象力，10分钟不看就999+消息。更关键的是**群体改进框架**——100多人用不同背景同时改 OpenClaw，没有把系统改坏，反而几小时迭代一轮。

> 我们基本上可能在三四周的时间做完了以前可能三四十周才能做到的事情，在研究上。

这让她深刻体会到：利用群体智能去提升 Agent 框架是 AGI 到来的前兆。

## 五、后训练范式的全面迁移

OpenClaw 带来的冲击让团队快速思考第二个问题：面对这么多复杂框架（Cursor、OpenClaw、Qwen），如何让模型在不同框架上都有稳定超预期的表现？

答案是：**整个后训练范式从 Chat 迁移到 Agent。**

这意味着：
- 构造真正的长程任务（软件开发是核心）
- 在 Agent 场景做大量 SFT 和 RL 训练
- 覆盖更多领域——让更多人用，发掘更广泛场景，合成更多数据

> Coding 有泛化力的最本质原因：它是一个非常长程和多轮的任务。真正能达到180K到一兆长度的数据，大概率只有代码和书籍。而代码的文件之间关联更强。

## 六、MiMo V2 的技术决策

### 为什么不用 MoE？

MoE 在 H 系列芯片上实现了访存和计算的完美平衡，但**没有可发挥的空间**。如果要用 MTP 加速推理，MoE 会卡在计算瓶颈上。

### Hybrid 架构 + MTP 的组合优势

MiMo V2 选择了 Hybrid 混合架构（Full Attention + Sliding Window），比例在 PRO 上做到了 7:1。通过 Sliding Window 减少 KV Cache，再用 MTP 填补释放的算力。

> 虽然我们设计模型没想那么多，但基本上就完美地非常适合 Agent。长上下文非常关键；很小的 KV Cache 很关键；速度是一个还蛮关键的命题。

实际效果：Flash 能做到 100-150 TPS，PRO 做到 60-100 TPS。用户第一感受就是"好快"。

### 三个模型的分工

- **PRO**：理解和认知，做更复杂的调度
- **Omni**：感知（音视频联合理解）
- **TTS**：声音输出，一种表达

> 这三个加起来是一种类人的智能吗？反正它把人有的智能的表象——输入和输出——给建模了。

## 七、多模态：NLP 人的执念与转变

罗福莉团队在音频上追求**离散化**——把连续输入变成离散 Token ID，用多层 RVQ 保证高位空间的无损表征。

> 就是做 NLP 的人的执念。我们做音频的人全是做 NLP 的人，所以有这个执念。

但最近一个月内发生了转变。以前追求统一架构是为了复用 Infra——同一套预训练架构、同一套 RL 架构，很优雅。但现在在 Agent 的帮助下，重写一套 RL 框架几个人两三周就能完成。

> Infra 重新写一套也没有那么复杂。你其实就没有必要为了架构的优雅性去做很多为了统一而统一的研究。

关于多模态能否促进智能，她的观察是：Omni 比 PRO 小，但对世界的感知和领悟力更强，情商和知识储备更好。

> 对感知力会更强，但是你在任何 Benchmark 上是纹丝不动的。

## 八、中美代差与2026年展望

罗福莉的判断：国内已有 1T+ 基座的公司（Kimi、MiMo 等），如果反应速度够快，**距离当代 Claude 4.6 Opus 只有两三个月代差**。

> 不是说两三个月过后能追上两三个月以后的 Claude，而是说能追上当代的 Claude。

关于 AGI 时间线：

> 感觉历程已经到了20%。今年至少能到60到70。AGI 很快了。我感觉两年内应该能实现。

她的自学习定义：模型可以自己训练自己、创造新的研究。

> 它先吸收所有人的智能，然后再靠自己产生更强的智能。我觉得这个事肯定是就在这一两年发生的事情。

2026年的胜负手：
1. 预训练基座不能错（>1T，Code 能力强）
2. Agent 框架与模型互相自迭代
3. Agent 架构耦合自身生态位（操作系统、硬件、流量）

> 其实它非常考验的是一个公司愿不愿意用一套新的方式来做这个事情。

## 九、组织哲学：环境比经验更重要

罗福莉团队的特点：大部分人没有大模型背景，55%有博士（含在读），越来越多招本科生。

> 这些能力最多一两个月，慢的话三四个月，确实都可以被快速习得。所以环境反而比经验更重要。

她的选人标准：技术好、好奇心强、热爱驱动。不在乎历史背景的"基因"好不好，只在乎初始化期望值和发展上限高不高。

团队管理哲学：极少在中间给强的监督信号。

> 你给太细节的监督信号告诉他这个事应该怎么做的，一个缺陷就是你会让团队的大部分人失去原创能力。

关于 RL 团队的特殊要求：要容忍模糊性。预训练绝对不能容错（出现 Loss Spike 就必须解决），但 RL 必须允许容错——Agent 框架交互中断、异构集群不一致性等都是常态。

## 十、框架进化的未来

罗福莉认为，当前所有"类 OpenClaw"产品大同小异——只是让 Front Court 变成类 Chat 形态。她还没看到：
1. **框架本身的自进化**
2. **Agent 与人之间的自进化**

> 真正那种去让框架自迭代、更强调自进化和自迭代的框架，还没有大规模诞生。

她的判断是：好的框架应该弥补行动上的缺陷——Memory 系统、Message Channel、主动性（心跳任务）、自我更新迭代。而真正缺失的一环是**可泛化的评估体系**——现在是最高阶那群人在当评估，框架需要把这些吸收为自动化的评判标准。

---

## 核心观点速览

1. **OpenClaw 是划时代的 Agent 框架**，核心逻辑是通过编排弥补模型短板，而非依赖单一顶级模型
2. **顶级模型与顶级框架必须共进化**，这就是"自学习"的发生途径
3. **群体智能是 AGI 的前兆**——100人同时改框架，几小时迭代一轮
4. **后训练范式已从 Chat 全面迁移到 Agent**，Coding 是核心突破口
5. **MiMo V2 的 Hybrid+MTP 架构天然适配 Agent**：长上下文高效、KV Cache 小、推理速度快
6. **MoE 不适合 Agent 时代**——没有留给 MTP 等加速手段的空间
7. **多模态促进感知但不一定促进智能**——Benchmark 纹丝不动，但体感更强
8. **中美代差约2-3个月**，AGI 两年内可能实现
9. **2026年主旋律**：高生产力场景的持续突破，更长程任务，Multi-Agent 协作
10. **环境比经验更重要**——选人看上限和热爱，不看历史背景
